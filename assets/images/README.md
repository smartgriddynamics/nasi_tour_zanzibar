# Add your website photos here

Save your photos in this folder using the exact filenames below. The site will use a local photo when it exists and keep its current fallback image until then. Your logo and favicon are separate and will not be changed.

Use `.jpg` files with these names. For the hero, use a wide landscape photo; for excursion and gallery photos, use landscape images where possible. Resize/compress large originals before adding them so pages load quickly.
